# 関節モーメントラボ

力学学習シリーズ第3弾。手先の荷重F₁と筋力F₂を変えて、肘関節の屈曲・伸展とモーメントの釣り合いを学ぶブラウザアプリです。

## 起動

[関節モーメントラボを起動する](https://joint-moment-lab-k.earlyjewel8.chatgpt.site)

現在は本人用の非公開版です。所有者のChatGPTアカウントでログインして利用します。

オフラインでは、このフォルダの `index.html` をブラウザで開いてください。インストールや外部ライブラリは不要です。

## 操作と表示

- F₁：0〜200 N、F₂：0〜2000 Nを数値やスライダーで変更
- 初期値F₁＝100 N、F₂＝1000 Nでは前腕が水平で釣り合う
- F₂のモーメントが大きければ屈曲、F₁側が大きければ伸展
- 「筋力を釣り合わせる」でF₂＝10F₁となり、その場で静止
- 一時停止・再生、前腕を水平に戻す、初期値に戻す操作
- 屈曲・伸展の端に達すると、短く止まって水平な開始姿勢に戻り、反復再生
- 筋肉は伸展側で青、屈曲側で濃い赤、釣り合いで淡い赤に変化
- 手の上の重りはF₁に応じて大きくなり、0 Nでは非表示
- M₁の矢印は手先側の固定位置、M₂の矢印は肘付近に表示
- 各矢印の付近と数値カードに、モーメントを小数点第1位まで表示
- モーメントアームの固定値を腕の図の下に表示

## 学習モデルの前提

モーメントアームは角度によらず、荷重側0.30 m、筋力側0.03 mで固定します。

- M₁＝F₁×0.30（伸展モーメント）
- M₂＝F₂×0.03（屈曲モーメント）
- 正味モーメント＝M₂−M₁

慣性・前腕の自重・筋の弾性を省いた準静的な表示です。角速度を正味モーメントに比例させ、釣り合うと直ちに静止します。実際の人体の運動速度や筋力を予測するモデルではありません。力の作用線と腕の姿勢は模式的な表示です。

表示上の動きは、開始姿勢90°から伸展側71.25°、屈曲側112.5°までです。端で0.4秒表示した後、開始姿勢に戻して繰り返します。自動リセットは学習のための演出で、逆向きの運動を力学的に計算したものではありません。
